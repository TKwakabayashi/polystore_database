# tpch — schema & sizes

TPC-H modeled as a graph (OLAP control). Customer->Order->Lineitem->Part / Supplier, generated by DuckDB's tpch extension.

- **Manifest name**: `tpch_graph`
- **Source**: DuckDB tpch extension
- **License / use**: TPC-H spec (synthetic, freely generable)
- **Placement**: all properties in `graph` (single-store Neo4j) — see `mapping.json`
